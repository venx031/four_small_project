# Ladies and Gentelmen! Embedded Developer and System Programmers!
Inside this repository is four small projects for embedded systems.

**First project** is Bootloader Reverse Engineering (**reverse_impl**).
Recovering and porting bootloader source code from ASM to C.

**Second project** is an interrupt driven UART + Ring Buffer implementation (STM32F401RE) (**Interrupt_driven_UART**).

**Third project** is a robust I2C sensor driver (STM32F401RE) (**I2C_sensor_driver**).

And finally **fourth project** is a RTOS priority-shedule implementation (**RTOS**).

---
**Used followed stack:**
* C language 
* objdump
* gcc & cross-compiler
* Arm assembly language 

---
> Every project in this collection reflects a "manual" approach to hardware — no bloated libraries,
just registers, assembly, and clean C code.
